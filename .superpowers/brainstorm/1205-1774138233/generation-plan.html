生成路径选择

A

AI 图像生成

用 FLUX / Stable Diffusion + 参考图 LoRA，直接生成STS2风格的立绘。
每张资产可多次迭代，挑最合适的。

✓ 速度最快（分钟级）
✓ 可大量迭代，不满意重生成
✓ Claude Code 可以直接调用
✗ 细节控制有限，需要后期调整
✗ 风格一致性需要反复提示词调整
推荐模型：inference.sh FLUX Dev · Grok Imagine · Gemini 3 Pro Image
B

裁剪 / 重绘参考图

直接对 R.jpg 进行裁剪特写，用图像工具（Photoshop/GIMP）调整为STS2扁平风格并适配各分辨率。

✓ 角色形象精确，与参考完全一致
✓ 无版权问题（自己处理）
✗ 需要手动美术工作，耗时
✗ 风格化处理难度较高
✗ Claude 无法直接操作图像编辑器
C

AI 生成 + 参考图引导（推荐）

用 R.jpg 作为风格参考/img2img，AI 生成STS2卡通扁平风版本，再针对各资产尺寸裁剪适配。

✓ 最大程度保留参考图的造型识别度
✓ 风格可控（指定STS2扁平插画风）
✓ Claude 可自动化完成全流程
✗ 需要多轮迭代找到满意结果
流程：R.jpg → AI img2img → STS2风格 → 裁剪出各资产
